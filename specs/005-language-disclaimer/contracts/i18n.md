# Contract: Texts, Language Switch and Disclaimer (TS-05)

Replaces the "Start page texts" table of [TS-04 contracts/health-ui.md](../../004-react-app-skeleton/contracts/health-ui.md); the start page states and API client are unchanged.

## Module `frontend/src/i18n/translations.js`

| Export | Behaviour |
|---|---|
| `translations` | `{ es: { key: text }, en: { key: text } }`; Spanish complete |
| `LANGUAGES` | `[{ code: 'es', short: 'ES', name: 'Español' }, { code: 'en', short: 'EN', name: 'English' }]` |
| `DEFAULT_LANGUAGE` | `'es'` |
| `translate(lang, key, dict = translations)` | `dict[lang]?.[key] ?? dict.es[key] ?? key` |
| `interpolate(text, values)` | replaces each `{name}` with `values[name]` when present; no `values` → text unchanged |

## Module `frontend/src/i18n/LanguageContext.jsx`

| Export | Behaviour |
|---|---|
| `LanguageProvider` | holds `lang`; initial value from `localStorage['pdm.language']` if `es`/`en`, else `es` (errors → `es`); sets `document.documentElement.lang` and `document.title` (`app.title`) whenever `lang` changes |
| `useLanguage()` | `{ lang, setLang, t }`; `t(key, values)` = `interpolate(translate(lang, key), values)`; `setLang` accepts only `es`/`en` and saves it (errors ignored). Throws outside the provider |

## Page frame `frontend/src/components/AppShell.jsx`

```text
<header class="app-header">            position: sticky; top: 0 (pinned, never covers content at the top)
  <p class="disclaimer" role="note">   t('disclaimer.text')
  <div role="group" aria-label=t('language.label')>
    <button aria-label="Español" aria-pressed=(lang==='es')>ES</button>
    <button aria-label="English" aria-pressed=(lang==='en')>EN</button>
</header>
{children}                             each screen, e.g. <StartPage />
```

No other buttons or controls in the frame; the banner can't be closed or hidden. `App.jsx` = `<LanguageProvider><AppShell><StartPage /></AppShell></LanguageProvider>`.

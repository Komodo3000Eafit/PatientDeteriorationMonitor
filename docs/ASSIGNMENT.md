# Assignment Summary

English summary of the course assignment *"Taller: Aplicación de Solución IA bajo Spec-Driven Development (SDD)"*. The original (in Spanish) is the authoritative version.

**Deadline:** 2026-11-24 18:00 · multiple submissions allowed

## Goal

Build and deploy a working end-to-end application (frontend, backend, database, DevOps and security) using Spec-Driven Development and AI tools — rigorous, incremental, verifiable development. Multi-agent architectures are especially valued.

## Technical requirements

- **Complete application** (topic chosen by the team)
- **Frontend:** functional and integrated UI
- **Backend:** services, APIs and business logic
- **Database:** persistence
- **SDD:** GitHub Spec Kit (preferred) or OpenSpec
- **DevOps:** deployed to an accessible environment, preferably free
- **Quality and security:** automated tests, validations, basic security practices
- **Backlog:** ~10 user stories — 5 implemented as the baseline, 5 built in class. The 5 in-class stories should be **independent** to avoid conflicts during concurrent development

## Grading modalities

- **Modality A — SDD with AI (max 4.5):** full process evidence: Specification → Planning → Tasks → Implementation → Tests → Deployment.
- **Modality B — SDD with a team of AI agents (max 5.0):** Modality A + a collaborative architecture of 2+ AI agents with differentiated responsibilities (e.g. coordinator + developer + tester; or frontend/backend/security/testing specialists). Agents must **actually execute work**, not just be described in a document. Effective collaboration is graded, not the number of agents. **← our choice**

## Mandatory in-person demo

1. **Baseline presentation:** deployed working app; ~5 stories implemented and ~5 pending; the specs used; automated tests and security controls; the agent architecture.
2. **Individual live development:** **every student**, from **their own computer**, builds a story assigned by the professor: write/adjust the spec, run the SDD process with AI (and the agents), implement, test and run it integrated with the app. About **5–10 minutes per spec**. Watching a teammate does not count.

## Rubric

| Criterion | Weight |
|---|---|
| Functional product (integrated app, stories, deployment, tests, security) | 30% |
| Application of SDD (quality and traceability of specs, plan, implementation, validation) | 30% |
| Individual live demo | 40% |

Modality B grade reaches 5.0 only if agent collaboration is **demonstrated working**.

## Deliverables

- Source code repository
- Specifications and user story backlog
- Installation and run instructions
- Link to the deployed app
- Evidence of tests and security controls
- Description of the multi-agent architecture
